# analogBEAST-field v1.0.0

First stable-design release, based on the tested 0.3.21 source.

- Standalone two-oscillator OP-1 Field synthesizer
- Three pages of colour-coded live editing, including SHIFT functions
- Seven explicit two-line titles: OSC2 SEMI, KEY TRACK, EG RESET, OSC2 TUNE, OSC1 WAVE, OSC2 WAVE, OSC2 MOD
- Choice parameters display labels and DIST shows ON/OFF
- Five integrated factory sounds

**Release binary:** `analogbeast.pack` (pack version 100, OS 1.7.3, base level 10).

The 1.0.0 pack passed the Blackfin cross-build and pack check. Publishing requires an on-device check of the exact release binary. The source ZIP does not contain the compiled `.pack`; the publication script takes it from the author's open-field checkout.
